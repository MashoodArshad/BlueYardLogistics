# Blue Yard Logistics

> **Intelligent Maritime Logistics & Cargo Flow Optimization Platform**

## 📌 Project Overview
Blue Yard Logistics is an integrated logistics platform designed to optimize cargo flow from vessel arrival to warehouse delivery. It combines Software Engineering best practices, Data Structures & Algorithms, Data Science analytics, and Computer Networks infrastructure simulation.

## 👥 Team Roles & Responsibilities
- **Member 1 (Computer Networks):** Network topology, VLANs (10/20/30/40), routing simulation in Cisco Packet Tracer.
- **Member 2 (DSA / C#):** Priority Queue, Yard Grid (2D Array), Graph representation, Dijkstra's algorithm, vehicle assignment.
- **Member 3 (IDS / Python):** Data preprocessing, cargo dwell-time & risk analytics, FastAPI microservice.
- **Member 4 (SE / Integration):** System architecture, Database design (SQL Server), ASP.NET Core API, Frontend UI, system integration.

## 🏗️ Tech Stack
- **Backend:** ASP.NET Core Web API (C# .NET 8/10)
- **Analytics Service:** Python 3.11 + FastAPI + pandas + numpy
- **Database:** Microsoft SQL Server (BlueYardDB)
- **Frontend:** HTML5, CSS3, JavaScript
- **Network Simulation:** Cisco Packet Tracer
